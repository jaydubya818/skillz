# Checkpoint 4 adapter

This is a finite qualification controller, not a production execution provider.
`myskills-tools/4.0.1` exposes four exact tools: `read_file`, `write_file`,
`run_check`, and `finish`. Their logical schemas are generated by `adapter.schemas`.
Codex's observed wire codec is separately checked by `provider.validate_native_request`.
The native binary advertises `request_user_input`; this is never granted. All
non-dynamic server RPCs are rejected. No shell, search, MCP discovery, or subagent
authority is granted.

Reads and compare-and-write operations affect only controller-owned synthetic
files. Check commands are fixture constants. Candidate code runs in a separate
offline container with no host mounts, a read-only root, unprivileged UID,
dropped capabilities, CPU/memory/PID limits and disposable tmpfs. Static syntax
checks run before candidate dispatch. They support these finite fixtures only;
they are not a general Python or JavaScript security sandbox. Filesystem
snapshots detect persistent changes, not every transient in-container action.

Every behavioral session binds Skill/version/digest, model/digest,
harness/version/digest, adapter/version/digest, task/fixture and environment.
The controller fsyncs a sealed dispatch record before effects and a completion
record afterward. Call IDs are idempotent within one live session. Reusing an ID
with different arguments fails. A pre-existing journal cannot resume implicitly;
an unmatched dispatch remains UNKNOWN and requires reconciliation.

Malformed arguments return an explicit error and may be corrected. Authority
requests, including `destination: null`, fail before dispatch. Nonzero test exit
codes are successful transport with failed test evidence. Missing cleanup is
fatal to the whole batch. Cancellation stops further tool dispatch and removes
owned containers. Provider deadline/cancellation disconnects the request but
cannot attest that the local daemon stopped inference; such a batch is
INCONCLUSIVE and receives no PASS.

The only inference destination is literal `127.0.0.1:11434`, using the pinned
manifest digest. There is no paid-provider fallback, proxy or redirect.
Model/runtime checks surround trials and requests; full bytes are hashed at
batch admission and completion. An interrupted batch is never admissible.

Run `python -m qualification.v4.controls --output <new-evidence-path>` for actual
container controls, and `python -m qualification.v4.probe --output <new-directory>`
for the explicitly authorized local native trial batch. Neither command promotes
catalog trust or activates consumers. Scripted native transport controls establish
protocol compatibility only, never model behavior.

The Acorn 8.15.0 reducer policy parses an AST without executing it. It accepts a
narrow pure-reducer grammar, including harmless comments containing `process`,
and rejects dynamic properties, calls, constructors, imports and global access.
This does not qualify browser workflows or unrestricted JavaScript execution.
